# Lidbar

Панель-«чёлка» для Windows: дела, заготовки, буфер обмена, плеер, видео и другое — под рукой у верхнего края экрана.

**Скачать:** последний установщик — в [Releases](https://github.com/rkubenov/lidbar-releases/releases/latest) (`Lidbar_…_x64-setup.exe`).

Установленный Lidbar обновляется сам: проверяет новую версию раз в сутки, а в «Настройках» есть кнопка «Проверить обновления». Каждое обновление подписано — программа не поставит файл без верной подписи.
